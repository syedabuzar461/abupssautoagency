# PSS Auto Agency

A dealership management dashboard built with Next.js, React, and TypeScript. It includes demo workflows for sales, customers, vehicles, expenses, outstanding payments, finance, reporting, and exports.

## Getting started

Install dependencies and start the development server:

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Demo sign-in

The local demo includes these role accounts, all using the password `pss123`:

- `admin`
- `manager`
- `staff`

This is demo-only authentication and sample data. Do not use the demo credentials or enter real customer, financial, or vehicle records in a public deployment. Authentication and cloud sync endpoints are mock implementations and are not suitable for production.

## Scripts

- `npm run dev` — run the development server
- `npm run build` — create a production build
- `npm run start` — run the production server
- `npm run lint` — run ESLint
